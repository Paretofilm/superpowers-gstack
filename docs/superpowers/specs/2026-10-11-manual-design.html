Ferdig når
  1. 1Alle elleve kapitler er skrevet, og hver kommando kan limes inn som den står
  2. 2Alle sju figurer er målt uten avklipt eller overlappende tekst
  3. 3Release-sjekken er grønn, og testene for byggetrinnet og sjekken består
  4. 4Du har åpnet siden og lest den
  5. 5Landet på main, med lenke fra README
